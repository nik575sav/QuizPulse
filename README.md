# «Веб-приложение QuizPulse»

## Введение
QuizPulse — это современное интерактивное веб-приложение для проведения многопользовательских викторин в реальном времени. Приложение позволяет пользователям создавать квизы с различными типами вопросов (одиночный и множественный выбор), загружать изображения, организовывать игровые комнаты по уникальному коду и участвовать в соревнованиях с актуальной таблицей лидеров и таймерами.
Основные возможности:
*	Регистрация и авторизация (организатор / участник).
*	Конструктор викторин с поддержкой медиа.
*	Реал-тайм игровые сессии через WebSocket.
*	Динамический подсчёт баллов и история игр.
*	Адаптивный, яркий интерфейс.
Проект реализован как полноценное SPA-приложение, ориентированное на удобство и скорость работы.

### 1. Обоснование выбора средств разработки
Выбор технологического стека был обусловлен требованиями к реальному времени, удобству разработки, производительности и современным практикам фронтенд-разработки.

1.1. Frontend
*	React + Vite — основной фреймворк. React обеспечивает удобную работу с состоянием и компонентами, а Vite даёт молниеносную сборку и разработку (HMR).
*	TypeScript — повышает надёжность кода, особенно в сложной логике игровых состояний и форм.
*	Tailwind CSS — утилитарный CSS-фреймворк, позволяющий быстро создавать современный, адаптивный дизайн без написания большого количества кастомных стилей.
*	Zustand — лёгкий менеджер состояния для авторизации и пользовательских данных.
*	Socket.io-client — клиентская часть для двусторонней связи в реальном времени.
Такой стек позволяет создавать сложные интерактивные интерфейсы (редактор вопросов, игровая комната) с отличной DX (Developer Experience) и быстрым рендерингом.

1.2. Backend
*	Node.js + Express (предполагается по API-эндпоинтам) — асинхронная среда, идеально подходящая для real-time приложений.
*	Socket.io — основная технология для синхронизации состояний комнат, таймеров, ответов участников и обновления лидерборда в реальном времени.
*	In-memory / JSON-хранилище (db.json) — удобно для прототипа и быстрого тестирования. Позволяет легко сохранять пользователей, квизы и активные комнаты.
*	REST API — для CRUD-операций с квизами и авторизацией.
Выбор Socket.io вместо чистого WebSocket обусловлен удобством (fallback-транспорты, rooms, events), что критично для стабильной работы при большом количестве участников.

### 2. Архитектура приложения
Приложение разделено на чёткие модули:
*	Авторизация (/auth) — вход/регистрация, хранение данных в localStorage + Zustand.
*	Дашборд — список созданных квизов, история участия.
*	Редактор квизов (QuizEditor) — динамическое добавление/редактирование вопросов, выбор типа (single/multi), установка таймеров и изображений.
*	Игровая комната (QuizRoom) — два режима отображения (для организатора и участника). Реал-тайм обновления через сокеты.
*	Backend — управление комнатами, состояниями игры (waiting → active → showing_results → finished), расчёт баллов, лидерборд.
Данные хранятся централизованно (пользователи, квизы, комнаты). Синхронизация состояний осуществляется через Socket.io events (join_room, room_state, submit_answer, organizer_action и др.).

### 3. Основные этапы разработки
Этап 1. Проектирование и инициализация
*	Настройка проекта на Vite + React + TypeScript.
*	Подключение Tailwind CSS, Zustand, Socket.io-client.
*	Проектирование структур данных (пользователи, квизы, комнаты).

Этап 2. Система авторизации и профиль
*	Реализация хранилища useAuthStore.
*	Страницы входа/регистрации.
*	Защита маршрутов (организатор/участник).

Этап 3. Конструктор викторин
*	Создание компонента QuizEditor.tsx.
*	Динамическое управление вопросами: добавление/удаление, смена типа (single/multi), редактирование вариантов, загрузка изображений по URL.
*	Сохранение/редактирование квизов через REST API.

Этап 4. Игровой движок (реал-тайм)
*	Разработка QuizRoom.tsx с двумя представлениями (организатор / игрок).
*	Интеграция Socket.io: подключение к комнате, синхронизация состояния, обработка таймеров.
*	Реализация логики вопросов, отправки ответов, показа результатов и перехода между вопросами.
*	Подсчёт баллов и формирование лидерборда.

Этап 5. UI/UX и полировка
*	Создание единого современного дизайна (вибрирующие карточки, градиенты, анимации).
*	Адаптивность под мобильные устройства.
*	Обработка состояний загрузки, ошибок и отключений.
*	Тестирование многопользовательского режима (несколько вкладок/устройств).

## Заключение
В результате разработки получено полноценное, современное и удобное приложение для проведения викторин. Использование React + Socket.io позволило добиться высокой интерактивности и плавной работы в реальном времени. Стек технологий обеспечивает хорошую масштабируемость: в дальнейшем возможно подключение полноценной базы данных (PostgreSQL/MongoDB), аутентификации через JWT, загрузки изображений и деплоя.
Проект демонстрирует компетенции в разработке full-stack приложений с акцентом на реал-тайм взаимодействие и качественный пользовательский интерфейс.
